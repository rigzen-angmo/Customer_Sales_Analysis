# Customer Sales Analysis

## Project Overview

This project analyzes customer shopping and sales data using Power BI and Power Query.

The main goal of the project is to understand customer buying patterns and sales performance based on gender, age groups, product categories, and payment methods.

## Dataset

The dataset contains customer shopping information from different shopping malls in Istanbul.

It includes approximately 99,000 transaction records and contains information such as:

- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price
- Payment Method
- Invoice Date
- Shopping Mall

## Data Preparation

The data was cleaned and prepared using Power Query in Power BI.

Main steps included:

- Checked the data for errors and missing values
- Corrected data types
- Converted the invoice date into Date format
- Created age groups using DAX
- Created a sorting column for age groups

## Analysis

The analysis focuses on:

- Shopping distribution by gender
- Products sold by gender
- Revenue generated by gender
- Purchase distribution by category
- Shopping distribution by age group
- Products sold by age group
- Revenue by age group
- Payment method distribution
- Relationship between customer demographics and shopping behavior

## DAX Used

Some DAX functions used in the project include:

- `SUMX`
- `COUNTROWS`
- `DISTINCTCOUNT`
- `SWITCH`
- `TRUE`

DAX was used to create calculated columns and measures for revenue, transactions, customers, and age groups.

## Key Insights

- Clothing had the highest number of purchases.
- Female customers generated higher revenue and quantity sold than male customers.
- The 36–45 age group generated the highest revenue.
- Customers aged 26–65 showed high shopping activity.
- Cash was the most commonly used payment method.

## Dashboard

The Power BI dashboard presents the main findings using charts, cards, and interactive visuals.
